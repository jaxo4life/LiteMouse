Principles

小，是有意为之

不堆砌功能，只把真正常用的操作做到顺手。

01原生零依赖

纯 Vanilla JS，无框架、无打包、无运行时。加载即用，源码可读，人人可审。

02隐私至上

不联网、不收集、不上报。所有设置与统计都留在你本机的浏览器里。

03随心定制

每个手势独立开关，灵敏度、路径配色、线条粗细皆可调，长成你顺手的样子。

Install

三步上手

开发者模式加载，无需上架商店。

从 Releases 下载源码压缩包并解压

打开 chrome://extensions，开启「开发者模式」

点击「加载已解压的扩展程序」，选择解压后的文件夹
